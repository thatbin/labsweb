bMusic は、お手持ちの音楽ファイルを iPhone / iPad に入れて再生するプレイヤーです。アカウントもストリーミングもありません。ご質問・不具合のご報告は support@shosin-labs.com までお送りください。日本語・English・中文で対応します。

まず: ライブラリが空です

bMusic はお客様ご自身の音楽ファイルを再生するアプリで、曲は付属していません。インストール直後のライブラリが空なのは正常です。「取り込み」タブから音楽を追加してください。

音楽を取り込む方法

  • パソコンから Wi-Fi で。「取り込み」→「Wi-Fi で取り込む」。表示された http:// のアドレスを同じ Wi-Fi につながったパソコンのブラウザで開き、ファイルをページにドロップします。同じページからライブラリの曲をパソコンへ戻すこともできます。
  • ファイル App / iCloud Drive から。「取り込み」→「クラウドから取り込む」でファイルやフォルダを選びます。
  • リンクから。「取り込み」→「URL から取り込む」に音声ファイルへの直接リンクを貼り付けます。
  • ほかのアプリ・AirDrop から。共有シートで bMusic を選びます。

対応フォーマット

MP3、AAC、M4A、ALAC、FLAC、WAV、AIFF。タグとアートワークは FLAC を含むすべての形式から読み取ります。

よくある質問

曲が表示されません。 取り込みが完了しているかご確認ください。大量のファイルは読み込みに時間がかかります。対応外の形式（例: WMA、OGG）は取り込まれません。

タグを編集しても保存されません。 タグの書き戻しは MP3、FLAC、MP4 系（M4A / AAC / ALAC）に対応しています。WAV と AIFF は非対応で、その旨が表示されます。

iCloud 同期が反映されません。 「設定」→「iCloud」でオンにしたあと、次回の起動から有効になります。同じ Apple アカウントでサインインし、ネットワークに接続されている必要があります。ライブラリが大きい場合、最初の同期には時間がかかります。

Last.fm に記録されません。 Last.fm 連携にはお客様ご自身の API キーが必要です（bMusic はキーを内蔵していません）。「設定」→「Last.fm」から設定してください。

購入した Pro が別の端末で有効になりません。 同じ Apple アカウントでサインインしたうえで「設定」→「bMusic Pro」→「購入を復元」をお試しください。

返金について。 App Store での購入の返金は Apple が扱います。reportaproblem.apple.com からお手続きください。

bMusic — Support

简体中文 ↓

bMusic plays the music files you already own, on your iPhone and iPad. No account, no streaming. For questions or bug reports, write to support@shosin-labs.com — in English, Japanese or Chinese.

First: the library is empty

bMusic plays your own audio files and ships with none, so an empty library on a fresh install is expected. Add music from the Import tab.

How to get music in

  • Over Wi-Fi from a computer. Import → "Import from Wi-Fi". bMusic shows an http:// address; open it in the browser of a computer on the same Wi-Fi and drop files onto the page. The same page downloads songs back to the computer.
  • From the Files app or iCloud Drive. Import → "Import from Cloud Services", then pick files or a whole folder.
  • From a link. Import → "Import from URL", paste a direct link to an audio file.
  • From another app or AirDrop. Choose bMusic in the share sheet.

Supported formats

MP3, AAC, M4A, ALAC, FLAC, WAV and AIFF. Tags and cover art are read from all of them, FLAC included.

Common questions

My songs don't appear. Check that the import finished; a large batch takes a while to read. Unsupported formats (WMA, OGG) are not imported.

Tag edits don't save. Writing tags back into the file works for MP3, FLAC and the MP4 family (M4A / AAC / ALAC). WAV and AIFF are not supported and say so rather than pretending.

iCloud sync isn't working. After turning it on in Settings → iCloud it takes effect at the next launch. You need to be signed into the same Apple Account with a network connection. A large library takes a while on the first sync.

Last.fm isn't scrobbling. Last.fm needs your own API key — bMusic embeds none. Set it up in Settings → Last.fm.

Pro isn't active on my other device. Sign in with the same Apple Account, then use Settings → bMusic Pro → "Restore Purchases".

Refunds. App Store purchases are refunded by Apple, at reportaproblem.apple.com.

bMusic 支持

bMusic 用来播放你自己的音乐文件，支持 iPhone 和 iPad。没有账号，也不串流。有问题或想反馈，请发送邮件至 support@shosin-labs.com，中文、English、日本語均可。

首先：曲库是空的

bMusic 播放的是你自己的音频文件，应用本身不附带歌曲，所以刚装好时曲库为空是正常的。请从"导入"标签添加音乐。

如何导入音乐

  • 用电脑通过 Wi-Fi。"导入"→"通过 Wi-Fi 导入"。bMusic 会显示一个 http:// 地址，在同一 Wi-Fi 下的电脑浏览器中打开它，把文件拖到页面上即可。同一页面也能把曲库里的歌下载回电脑。
  • 从文件 App 或 iCloud 云盘。"导入"→"从云服务导入"，选择文件或整个文件夹。
  • 从链接。"导入"→"从 URL 导入"，粘贴音频文件的直接链接。
  • 从其他应用或隔空投送。在共享菜单里选择 bMusic。

支持的格式

MP3、AAC、M4A、ALAC、FLAC、WAV 和 AIFF。标签与封面从所有这些格式中读取，包括 FLAC。

常见问题

歌曲没有出现。请确认导入已完成；文件较多时读取需要一些时间。不支持的格式（如 WMA、OGG）不会被导入。

编辑标签后没有保存。把标签写回文件支持 MP3、FLAC 和 MP4 系列（M4A / AAC / ALAC）。WAV 与 AIFF 不支持，应用会明确提示。

iCloud 同步没有生效。在"设置"→"iCloud"中打开后，需要下次启动才生效。需要登录同一个 Apple 账户并保持联网。曲库较大时首次同步需要较长时间。

Last.fm 没有记录。Last.fm 需要你自己的 API 密钥，bMusic 不内置。请在"设置"→"Last.fm"中配置。

另一台设备上 Pro 没有生效。请用同一个 Apple 账户登录，然后使用"设置"→"bMusic Pro"→"恢复购买"。

关于退款。App Store 购买的退款由 Apple 处理，请前往 reportaproblem.apple.com。
